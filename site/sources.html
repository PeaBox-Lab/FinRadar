Data Sources Catalog

FinRadar computes KPIs from these public government sources. Each row links to the live API or catalog page.

World Bank Open Data

  • api.worldbank.org/v2 — GDP, inflation, trade, PPP, demographics across 200+ countries.

data.gov.in (OGD Platform)

  • Economy sector — 500+ APIs: GDP, GST, inflation, fiscal, trade.
  • Power & Energy — 300+ APIs: generation, renewables, consumption.
  • Agriculture — crops, fertilizer, irrigation, wages.
  • Health & Family Welfare — hospital stats, immunization, NFHS.
  • Transport — Vahan, roads, vehicle registrations.
  • Labour & Employment — MGNREGA, wages, PLFS.
  • MSME Udyam registrations — unit-level state/district data.

API Setu (apisetu.gov.in)

  • API Directory — 4,200+ published APIs across 2,700+ organisations.
  • Key APIs: DigiLocker, GSTN, MCA, Vahan, UIDAI, NPCI, PPAC, CBSE, IRCTC.

RBI & NPCI

  • RBI DBIE — interest rates, reserves, sectoral credit, money supply.
  • NPCI — UPI/IMPS/FASTag volumes, ticket sizes.

IMF / FRED

  • IMF DataMapper — fiscal, debt, cross-country comparables.
  • FRED — US rates, commodities, global indicators.
